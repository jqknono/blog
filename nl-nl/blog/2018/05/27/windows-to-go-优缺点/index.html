Windows To Go: Voordelen en nadelen

Windows To Go Overzicht

Windows To Go is een functie van Windows Enterprise en Education. De meeste thuisklanten gebruiken de Home-editie, die deze functie niet heeft. Het stelt ons in staat om een draagbaar Windows-systeem te maken dat opstart vanaf een USB-stick of harde schijf. Windows To Go is niet bedoeld om traditionele werkgereedschappen te vervangen. Het belangrijkste doel is om mensen die vaak van werkplek wisselen efficiënter te maken. Voordat u Windows To Go gebruikt, moet u zich bewust zijn van de volgende punten:

  • De verschillen tussen Windows To Go en de traditionele installatiemethode van Windows;
  • Windows To Go gebruiken voor mobiel werken;
  • Voorbereiden op de installatie van Windows To Go;
  • Hardwarevereisten.

Verschillen tussen Windows To Go en traditionele Windows-installaties

De werkomgeving van Windows To Go is bijna hetzelfde als die van traditioneel Windows, met uitzondering van de volgende punten:

  • Behalve de gebruikte USB-stick staan de andere harde schijven van de computer standaard offline. Dit betekent dat ze niet zichtbaar zijn in de Verkenner, dit is ter bescherming van de gegevens. [J] Maar er zijn nog steeds manieren om andere schijven zichtbaar te maken en de bestanden erin te wijzigen.
  • TPM (Trusted Platform Module) is niet beschikbaar. De TPM-module is gekoppeld aan een specifieke computer om zakelijke gegevens te beschermen. [J] De meeste consumenten-pc’s hebben geen TPM-module, maar als uw zakelijke pc al lid is geworden van het domein van uw bedrijf, is het beter om niet te proberen Windows To Go op die pc te gebruiken, anders wordt u aangeraden om uw cv voor uw volgende baan voor te bereiden.
  • De slaapstand (Hibernate) van Windows To Go is standaard uitgeschakeld, maar kan via groepsbeleid worden ingeschakeld. [J] Veel machines verbreken de verbinding met USB-apparaten in de slaapstand, waardoor ze niet uit de slaapstand kunnen worden gehaald. Dit is heel begrijpelijk. Microsoft heeft hier al voor ons rekening mee gehouden, dus het is niet nodig om deze instelling te wijzigen.
  • De herstelfunctie (Restore) van Windows is uitgeschakeld. Als het systeem problemen ondervindt, moet Windows opnieuw worden geïnstalleerd.
  • Terugzetten naar fabrieksinstellingen is niet beschikbaar, Windows resetten is niet beschikbaar.
  • Upgrades zijn niet beschikbaar. Windows blijft op de versie van de installatie staan, het kan niet worden geüpgrade van Windows 7 naar 8, en ook niet van Windows 10 Redstone 1 naar Redstone 2.

Windows To Go gebruiken voor mobiel werken

Windows To Go kan worden gebruikt op meerdere computers. Het systeem bepaalt automatisch de stuurprogramma’s die nodig zijn om op te starten. Sommige toepassingen die sterk gekoppeld zijn aan de systeemhardware werken mogelijk niet. [J] Bijvoorbeeld het instelprogramma van het ThinkPad-touchpad, het instelprogramma voor vingerafdrukherkenning, enz.

Voorbereiden op de installatie van Windows To Go

U kunt System Center Configuration Manager of standaard implementatiehulpmiddelen voor Windows gebruiken, zoals DiskPart, Deployment Image Servicing and Management (DISM). Houd rekening met de volgende problemen:

  • Zijn er stuurprogramma’s die in de Windows To Go-image moeten worden geïnjecteerd?
  • Hoe kunnen gegevens op de juiste manier worden opgeslagen en gesynchroniseerd wanneer u op verschillende machines werkt?
  • 32-bit of 64-bit? [J] Nieuwe machines ondersteunen allemaal 64-bit, machines met 64-bit processors kunnen ook 32-bit systemen draaien, 32-bit processors kunnen geen 64-bit systemen draaien, 64-bit systemen nemen meer schijfruimte en geheugen in beslag tijdens het draaien. Als de processorarchitectuur van de machines die u wilt gebruiken alleen 32-bit processors ondersteunt, of als het geheugen van de machine minder dan 4 GB is, wordt u aangeraden een 32-bit systeem te gebruiken.
  • Welke resolutie moet worden ingesteld voor externe verbindingen vanuit netwerken buiten het samenwerkingsnetwerk?

Hardwarevereisten

USB harde schijf of USB-stick

Windows To Go is speciaal geoptimaliseerd voor de volgende apparaten om aan de eisen te voldoen, waaronder:

  • Geoptimaliseerde hoge willekeurige lees- en schrijfbewerkingen op USB-apparaten, zodat dagelijkse handelingen soepeler verlopen.
  • Windows 7 en latere systemen kunnen opstarten op gecertificeerde apparaten.
  • Zelfs bij het gebruik van Windows To Go geniet het USB-apparaat van de fabrieksgarantie. [J] Er is niet gezegd dat de computer waarop de USB-stick is aangesloten onder de garantie valt.

Niet-gecertificeerde USB-apparaten ondersteunen het gebruik van Windows To Go niet. [J] Of het wel of niet werkt, kunt u gewoon proberen, als het niet werkt, weet u ook waarom. [J] Er zijn online alternatieve methoden om de fabrikant en het model van de USB-stick te wijzigen om geforceerde ondersteuning te bereiken, maar ik zal hier niet in detail op ingaan.

Hostcomputer (Host computer)

  • Gecertificeerd voor ondersteuning van Windows 7 en latere systemen.
  • Computers met het Windows RT-systeem worden niet ondersteund.
  • Apple Mac-computers worden niet ondersteund. [J] Hoewel het internet vol staat met ervaringen over het draaien van Windows To Go op Mac, zegt de officiële documentatie duidelijk dat het scenario van het gebruik op Mac niet wordt ondersteund.
